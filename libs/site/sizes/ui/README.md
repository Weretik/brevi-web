# site-sizes-ui

Blocks of the «Таблиця розмірів» page in the «Строчка» design. See the [feature card](../../../../docs/features/site/sizes.md).

- `data/size-chart.ts` — charts and lookup functions.
- `i18n/sizes-dictionary.ts` — text in `uk` and `ru`.
- `sections/` — `SizeFinder` (client), `SizeTables`, `MeasureSteps`.

Tests: `npx nx test site-sizes-ui`.
