# site-articles-feature

Bodies of the «Статті» pages. See the [feature card](../../../../docs/features/site/articles.md).

- `ArticlesPage` — the list of all articles.
- `ArticlePage` — one article with the call to order and three more articles.
- `articleHref`, `toArticleSeoInput` — the link and the SEO input of an article in one language.

Tests: `npx nx test site-articles-feature`.
