# site-articles-feature

Bodies of the «Статті» pages. See the [feature card](../../../../docs/features/site/articles.md).

- `ArticlesPage` — the list of the articles the route reads.
- `ArticlePage` — one article with the call to order and the other articles the route picks.
- `articleHref`, `toArticleSeoInput` — the link and the SEO input of an article (search texts or title and excerpt).

Tests: `npx nx test site-articles-feature`.
