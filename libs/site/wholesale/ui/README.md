# site-wholesale-ui

Blocks of the «Ціни для опту» page in the «Строчка» design. Server Components only. See the [feature card](../../../../docs/features/site/wholesale.md).

- `i18n/wholesale-dictionary.ts` — page text in `uk` and `ru`.
- `sections/` — `WholesaleHero` (lead and wholesale terms), `WholesaleTiers` (three price levels by quantity, no prices), `WholesaleRange`, `WholesaleReasons`, `WholesaleOrder` (four steps and actions).

Tests: `npx nx test site-wholesale-ui`.
