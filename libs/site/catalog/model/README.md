# site-catalog-model

Catalog model of the public site. See the [feature card](../../../../docs/features/site/catalog.md).

- `catalog-tree.ts` — the category tree (`CATALOG_TREE`), `findCatalogPath`, `flattenCatalogTree`. The tree data in `data/` is generated by `tools/site-catalog-import`.
- `catalog-category.ts` — types of a category page and a product card.
- `catalog-sections.ts` — `CATALOG_SECTIONS` for the mega menu, the footer, the mobile bar, and the home page.

Tests: `npx nx test site-catalog-model`.
