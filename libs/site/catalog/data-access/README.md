# site-catalog-data-access

The only reader of catalog data. See the [feature card](../../../../docs/features/site/catalog.md).

- `catalog-source.ts` — `getCatalogCategory`, `getCatalogCategoryProducts`, `getCatalogCategorySlugs`. The functions are async so the BreviERP public API can replace the snapshot without changing the pages.
- `snapshot/` — categories and products of the old site, generated by `tools/site-catalog-import`. Server only: do not import this library from a client component.

Tests: `npx nx test site-catalog-data-access`.
