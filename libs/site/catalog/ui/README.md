# site-catalog-ui

Blocks of the catalog pages in the «Строчка» design. See the [feature card](../../../../docs/features/site/catalog.md).

- `i18n/catalog-dictionary.ts` — page text in `uk` and `ru`, the «N моделей» plural.
- `sections/` — `CatalogSectionsGrid` (catalog root), `CatalogSubcategories`, `CatalogProductGrid` (photo, name, «Дізнатися ціну»), `CatalogText` (category text), `CatalogOrder`.

Tests: `npx nx test site-catalog-ui`.
