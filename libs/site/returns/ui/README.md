# site-returns-ui

Blocks of the «Повернення та обмін» page in the «Строчка» design. Server Components only. See the [feature card](../../../../docs/features/site/returns.md).

- `i18n/returns-dictionary.ts` — page text in `uk` and `ru` as groups of items.
- `sections/` — `ReturnsGroups` (cards of rules, optionally numbered), `ReturnsGeneral` (general rules with the law link).

Tests: `npx nx test site-returns-ui`.
