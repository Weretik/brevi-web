# site-industries-ui

Blocks of the «Галузі» page in the «Строчка» design. Server Components only. See the [feature card](../../../../docs/features/site/industries.md).

- `i18n/industries-dictionary.ts` — page text in `uk` and `ru`.
- `sections/` — `IndustriesHero` (lead and terms), `IndustriesList` (eight industries), `IndustriesSteps` (three steps to a quote), `IndustriesFaq`, `IndustriesOrder` (actions).

Tests: `npx nx test site-industries-ui`.
