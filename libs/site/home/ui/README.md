# site-home-ui

Blocks of the home page in the «Строчка» design. Server Components only. See the [feature card](../../../../docs/features/site/home.md).

- `i18n/home-dictionary.ts` — home text in `uk` and `ru`.
- `layout/home-section.tsx` — block frame: stitch label, `h2`, action link.
- `sections/` — `HomeHero`, `HomeCatalog`, `HomeLogo`, `HomeProcess`, `HomeProduction`, `HomeIndustries`, `HomeContacts`, `HomeSeoText`.

Tests: `npx nx test site-home-ui`.
