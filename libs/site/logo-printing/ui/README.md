# site-logo-printing-ui

Blocks of the «Пошиття з логотипом» page in the «Строчка» design. Server Components only. See the [feature card](../../../../docs/features/site/logo-printing.md).

- `i18n/logo-printing-dictionary.ts` — page text in `uk` and `ru`.
- `sections/` — `LogoPrintingHero` (lead and order terms), `LogoPrintingMethods` (three methods with advantages), `LogoPrintingGarments`, `LogoPrintingSewing`, `LogoPrintingOrder` (four steps and actions).

Tests: `npx nx test site-logo-printing-ui`.
