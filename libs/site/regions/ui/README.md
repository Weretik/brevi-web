# site-regions-ui

Blocks of the «Регіони» page in the «Строчка» design. Server Components only. See the [feature card](../../../../docs/features/site/regions.md).

- `i18n/regions-dictionary.ts` — page text in `uk` and `ru`.
- `sections/` — `RegionsHero` (lead and delivery terms), `RegionsSteps` (four steps of an order from another city), `RegionsCities` (cities as text), `RegionsLocal` (Poltava), `RegionsOrder` (actions).

Tests: `npx nx test site-regions-ui`.
