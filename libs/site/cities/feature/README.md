# site-cities-feature

`SewingCityPage` and `WorkwearCityPage`: the bodies of the «Пошиття» and «Робочий одяг» city pages. They order the blocks of `site-cities-ui`, add the models carousel, the delivery map, `BreadcrumbList` and `FAQPage`. See the [feature card](../../../../docs/features/site/city-pages.md).

Tests: `npx nx test site-cities-feature`.
