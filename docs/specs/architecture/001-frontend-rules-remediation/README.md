## Split list

A component is split when it renders two or more independent blocks, defines subcomponents or hooks inline, reads more than one data source, or holds page logic (URL state, imports, confirmations) in JSX. Long column definitions alone are not a reason.

| `users/feature/src/pages/access-rights-page.tsx` (379)                                            | Page + role panel + unsaved-tab guard + loading states inline | `AccessRolePanel` and role summary in `users/ui`; tab/draft state in a hook |

| `production/ui/src/orders/production-order-filters.tsx` (308)                                     | Four components in one file                                   | one file per filter group                                                   |
