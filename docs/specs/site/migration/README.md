# Витрина Brevi на Next.js: план миграции

**Статус:** план, кода нет. Каждый шаг оформляется отдельным SDD в варианте `nextjs` с обязательным `design/seo.md` (скил `frontend-feature-spec`) и уходит отдельным PR. Слияние только с согласия владельца.
**Дата:** 2026-10-30.
**Связано:**

- [идея и дизайн «Строчка»](../../../ideas/storefront-nextjs/README.md);
- [ADR-0001](../../../architecture/site/adr/0001-nextjs-public-site.md);
- [архитектура сайта](../../../architecture/site/README.md);
- [SEO-архитектура](../../../architecture/site/platform/seo-architecture.md);
- [опись страниц и SEO-анализ](feature-inventory.md);
- [дизайн-система](../../../standards/site/design-system.md).

**Образец:** публичный сайт Кедра, kedr-web `apps/site` и его `docs/specs/site/migration/README.md`.

## Цель

Пересобрать витрину Brevi `apps/storefront` (Angular) как новый сайт `apps/site` на Next.js App Router, shadcn/ui и Tailwind CSS v4 в дизайне «Строчка». Потом переключить на него домен brevi.com.ua, где сейчас работает старый сайт на OpenCart.

- Сильное SEO с первого шага.
- Ни один старый адрес brevi.com.ua не теряется: каждый получает 301 на новую страницу.
- Покупатель приходит к звонку или заявке.

Бизнес: собственный пошив спецодежды с логотипом в Полтаве и продажа СИЗ, в первую очередь оптом. Заказ от 5 штук, три уровня цены (1–9, 10–39, 40+).

**Основа — витрина и BreviERP.**

- Набор страниц, переводы `uk` и `ru`, фото и картинки берём из `apps/storefront` и `libs/storefront`.
- Каталог, цены и тексты приходят из BreviERP и правятся в его админке.
- Старый сайт служит только справочником: какие разделы и страницы должны быть и какие старые адреса перенаправить. Его базу не импортируем.
- Angular-код не переносим. После переключения домена `apps/storefront` удаляется отдельным PR.

## Правила для всех шагов

1. **Адреса как у Кедра:** `/uk/...` и `/ru/...` со слагами из BreviERP. Таблица адресов есть в [SEO-архитектуре](../../../architecture/site/platform/seo-architecture.md). Старые адреса brevi.com.ua получают 301 по карте редиректов. Схема утверждена владельцем 2026-10-30.
2. **Новый сайт живёт на превью-домене Cloudflare** с выключенной индексацией до шага 10.
3. **Проекты и компоненты создаются командами,** не вручную: `npx nx g @nx/next:application`, `npx nx g @nx/react:library`, `npx shadcn@latest add`. Потом вывод генератора приводится к правилам репозитория. Так проекты видны в графе Nx.
4. **Каждый шаг заканчивается аудитом изменённого кода** (`frontend-code-audit`): большие файлы разбиваются, переполненные папки группируются.
5. **На каждом шаге проверяется SEO:**
   - тесты билдеров;
   - `curl`-проверка HTML: статус, title, description, canonical, hreflang, JSON-LD;
   - строка в таблице URL-политики.
6. **Данные идут только через `site-shared-api-client`** и доменный `data-access`. Сгенерированные типы не выходят из `data-access`. Цены, тексты и наличие приходят из API.
7. **Тексты, цены и фото задаются в админке BreviERP или в переводах сайта,** код их только выводит.

## Решения владельца

- Дизайн «Строчка», вариант 1 (2026-10-30).
- Стек как у Кедра: Next.js App Router, Tailwind CSS v4, shadcn/ui, lucide (2026-10-30).
- Хостинг Cloudflare (2026-10-30).
- Адреса как у Кедра: `/uk` и `/ru`, слаги из BreviERP, 301 со всех старых адресов (2026-10-30).
- Основа — витрина Brevi и данные BreviERP. Старый сайт нужен только как список страниц, экспорт его базы не нужен (2026-10-30).
- Главное SEO и практичность. Главное действие — звонок или заявка, без оплаты на сайте (анкета, 2026-10-30).
- Три уровня цены 1–9, 10–39, 40+. Оптовые цены видят все, розница не в приоритете (анкета, 2026-10-30).
- Без баннеров, видео и анимации, светлый сайт (анкета, 2026-10-30).

## Риски

- **Потеря позиций при переезде.**
  - Риск: старые адреса сменятся.
  - Снижение: полная карта 301 с каждого старого адреса на ближайшую по смыслу новую страницу. Плюс hreflang и JSON-LD, которых раньше не было, sitemap и Search Console. Переключаем только после аудита.
- **Пустой каталог в BreviERP.**
  - Риск: сайту нечего показывать.
  - Снижение: шаг 2 начинается сразу. Описания, SEO-тексты и фото вносятся в админке до шагов 4–5.
- **Шаблонные региональные страницы.**
  - Риск: поиск может понизить их как дорвеи.
  - Снижение: уникальный текст или одна страница «Доставка по Україні».
- **Фото товаров.**
  - Риск: от них зависит вид минималистичного сайта.
  - Снижение: единый формат фото на белом, заказчик готовит их заранее.
