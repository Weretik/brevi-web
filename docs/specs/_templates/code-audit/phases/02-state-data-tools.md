# Фаза 02 — State, API, DTO та інструменти

1. Простежте кожен query/mutation від UI до transport.
2. Підтвердьте approved repository stack фактичним provider/base API/config.
3. Знайдіть direct `fetch`/Axios, ручний server lifecycle/cache і API calls із UI.
4. Перевірте generated DTO boundary, runtime validation, mapper, cancellation,
   normalized errors, cache keys та invalidation.
5. Створіть ordered tasks для одного canonical data path і видалення обходів.

**Checkpoint:** для кожного server flow визначено один approved owner/path,
focused evidence і remediation task для кожного обходу.
