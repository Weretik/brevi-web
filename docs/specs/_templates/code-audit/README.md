# Модуль аудиту відповідальностей коду

Це окремий модуль SDD для аудиту наявного та впровадженого коду feature.
Він застосовується разом із [шаблоном feature](../feature/README.md), але не є
частиною каталогу `feature/`.

Скопіюйте [audit.template.md](audit.template.md) до
`<feature>/code-audit/audit.md` і заповнюйте його перед реалізацією та перед
delivery checkpoint. Для вже створеної feature додайте лише цей каталог,
не копіюючи повторно основний шаблон.

Аудит має зафіксувати точні шляхи й рішення для кожної області в межах feature:
залишити цілісною, розділити незалежні відповідальності на файли чи компоненти
або перенести до відповідних наявних каталогів і модулів. Після структурних
змін повторіть цільові тести та регресію. Сторонній рефакторинг не входить до
цього модуля.
