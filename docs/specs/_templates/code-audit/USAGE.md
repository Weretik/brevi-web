# Запит для аудиту коду feature

```text
Працюй за `docs/specs/_templates/code-audit/`.
Feature: `<точний шлях до feature>`.
Scope: `<уся feature або точна дозволена частина>`.

Перевір наявний і впроваджений код, файли, компоненти, каталоги та модулі.
Розділи незалежні відповідальності в межах scope, запиши причини рішень і
повтори відповідні тести, lint, typecheck та build.
```

## Приклад для delivery checkpoint

```text
Працюй за docs/specs/_templates/code-audit/.
Scope: уся feature которую ты внедрил
Перевір наявний і впроваджений код, файли, компоненти, каталоги та модулі.
Розділи незалежні відповідальності в межах scope, запиши причини рішень і
повтори відповідні тести, lint, typecheck та build.
```

Цей запит можна використати окремо для вже реалізованої feature або разом із
`ai-feature-workflow/` до delivery checkpoint.
