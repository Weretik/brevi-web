# Готовність remediation SDD

- [ ] Scope/exclusions і observable behavior to preserve визначені.
- [ ] Кожен `AF-*` має evidence, severity, impact і target state.
- [ ] Кожен `AR-*` посилається на узгоджене architecture/standard source.
- [ ] As-is inventory включає projects/tags/targets/imports/tools/tests.
- [ ] Target tree, ownership і dependency matrix точні та реалізовні Nx rules.
- [ ] Migration sequence не залишає невизначених проміжних owners.
- [ ] Кожен finding покритий `RM-*` і потрібними `EN-*`.
- [ ] Characterization/focused/regression evidence визначене до moves.
- [ ] Code audit підключений; blockers і dependencies повні.
