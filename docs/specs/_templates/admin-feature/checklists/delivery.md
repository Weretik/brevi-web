# <назва Admin feature> — delivery checklist

- [ ] Реалізовані всі погоджені сценарії та loading/empty/error/forbidden стани.
- [ ] Межі `model`, `data-access`, `ui` і `feature` дотримано.
- [ ] DTO не виходять із `data-access`; немає deep imports.
- [ ] Перевірені keyboard/focus, accessible names і responsive поведінка.
- [ ] Виконані `npx nx lint <project>`, цільові tests і `npx nx build admin` або причина пропуску записана.
- [ ] Виконана Test strategy; результати unit, integration, component і e2e/n-a рішення записані.
- [ ] Перевірені погоджені security scenarios: access, 401/403, error exposure і PII/logging.
- [ ] Зазначені ручні перевірки та залишкові ризики.
