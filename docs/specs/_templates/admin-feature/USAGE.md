# Як створити та реалізувати Admin feature

Надішліть AI це повідомлення для підготовки специфікації:

```text
Працюй за шаблоном `docs/specs/_templates/admin-feature/`.
Створи специфікацію Admin feature `<NNN>-<feature-slug>` у домені `<domain>`.
Мета: `<що має змінитися для користувача або бізнесу>`.
Scope: `<що входить і що явно не входить>`.
```

Приклад:

```text
Працюй за шаблоном `docs/specs/_templates/admin-feature/`.
Створи специфікацію Admin feature `002-product-archive` у домені `catalog`.
Мета: адміністратор може архівувати товар, щоб прибрати його з активного каталогу без втрати історії.
Scope: data-access, feature, UI, API-контракт і перевірки; зміни мобільного застосунку не входять у scope.
```

AI має скопіювати `admin-feature/` до
`docs/specs/admin/<domain>/<NNN>-<feature-slug>/`, замінити всі плейсхолдери,
заповнити вимоги й технічний план та закрити `checklists/requirements.md` **до**
реалізації коду.

Для виконання вже підготовленої feature по одній фазі використовуйте шаблон
`ai-task-workflow/`. Не просіть AI одночасно створювати специфікацію та
реалізовувати всі фази.
