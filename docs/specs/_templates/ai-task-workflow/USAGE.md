# Як запускати AI для однієї фази

Надішліть AI це повідомлення:

```text
Працюй за регламентом `docs/specs/_templates/ai-task-workflow/`.
Задача: `<шлях до feature або конкретного файла фази>`.
Поточна фаза: `<00 | 01 | 02 | …>`.
```

Приклад:

```text
Працюй за регламентом `docs/specs/_templates/ai-task-workflow/`.
Задача: `docs/specs/mobile/catalog/001-product-catalog`.
Поточна фаза: `00`.
```

Для наступної фази надішліть окрему команду:

```text
Переходь до фази 01.
```

Без цієї команди AI не має переходити до наступної фази.
