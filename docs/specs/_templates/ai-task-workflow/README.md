# Регламент поетапного виконання задачі

Виконуй передану користувачем фазу задачі за таким порядком:

1. Знайди і прочитай файл поточної фази в `<feature>/tasks/` та застосовні
   `AGENTS.md`.
2. Прочитай `spec.md` і всі документи, на які посилається поточна фаза.
3. Виконай лише checkbox-задачі поточної фази; не починай наступну.
4. Після виконання кожної задачі познач її `[x]` у файлі поточної фази.
5. Виконай релевантні перевірки, зафіксуй результат і надай підсумковий звіт.
6. Зупинись та чекай явної команди на наступну фазу.

## Детальний регламент

- [Контекст і межі роботи](01-context-and-scope.md) — як визначити потрібний
  файл фази, що читати, як перевірити залежності та коли зупинитися з blocker.
- [Виконання і фіксація результату](02-execution-and-records.md) — як вносити
  зміни, позначати задачі та оновлювати feature-документи.
- [Перевірка і передача фази](03-verification-and-handoff.md) — які перевірки
  виконати, як зафіксувати доказ і у якому форматі завершити фазу.
