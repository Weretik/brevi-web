# Виконання і фіксація результату

## Виконання checkbox-задач

1. Виконуй задачі у порядку, заданому у файлі фази, якщо там прямо не позначено,
   що вони незалежні.
2. Перед зміною файлу прочитай його поточний вміст і збережи існуючі рішення,
   формат, кодування та не пов'язані зміни користувача.
3. Внось найменшу зміну, яка повністю закриває поточну checkbox-задачу.
4. Після завершення кожної задачі перевір її локальний результат і заміни тільки
   її позначку `- [ ]` на `- [x]` у файлі поточної фази.
5. Не позначай задачу виконаною, якщо вона частково зроблена, заблокована або не
   перевірена. Залиш її `- [ ]` і чітко опиши причину в checkpoint або у
   фінальному звіті.

## Де фіксувати результат

| Подія                                                | Де фіксувати                                                                                                               |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Завершено конкретну задачу `T…`                      | У поточному `tasks/<фаза>-*.md`: `- [ ]` → `- [x]`.                                                                        |
| Уточнено scope, route, контракт або source paths     | У відповідному `spec.md`, `plan.md`, `research.md`, `data-model.md` або `contracts/api-contract.md`. Не дублюй інформацію. |
| Виявлено відсутній або неоднозначний контракт/вимогу | У профільному документі feature і в checkpoint поточної фази.                                                              |
| Виконано команди, device/web/manual перевірку        | У `quickstart.md` із точною командою, результатом і платформою.                                                            |
| Завершено delivery-фазу                              | Додатково заповни `checklists/delivery.md`, якщо він є і це вимагає фаза.                                                  |

Не став позначки в задачах майбутніх фаз і не заповнюй delivery checklist до
delivery-фази, якщо поточна задача прямо цього не вимагає.
