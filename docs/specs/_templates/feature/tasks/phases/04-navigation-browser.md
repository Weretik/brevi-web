# Фаза 04 — Планування навігації та браузерних адаптерів

Створюйте окремі файли `TS-*` для поведінки маршрутів і глибоких посилань, а
також для кожної відповідальності за браузерне сховище, файли, буфер обміну чи
дозволи. Використовуйте інтеграційні тести на реальній межі, доступній у
репозиторії.

**Контрольна точка:** маршрути, глибокі посилання, життєвий цикл, відхилені
дозволи та помилки адаптерів мають явно визначених власників і свідчення.
