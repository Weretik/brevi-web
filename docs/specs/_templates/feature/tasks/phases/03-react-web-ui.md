# Фаза 03 — Планування інтерфейсу React Web

Створюйте одну `TS-*` для кожної взаємодії користувача або візуального стану,
які можна перевірити окремо. Плануйте компонентні тести для семантики,
клавіатури, фокуса та спостережуваної поведінки завантаження, порожнього стану,
помилки, заборони й успіху. Використовуйте точні наявні або запропоновані шляхи.

**Контрольна точка:** кожна вебвзаємодія підтверджена фокусними компонентними
свідченнями; E2E зарезервовано для критичних сценаріїв користувача.
