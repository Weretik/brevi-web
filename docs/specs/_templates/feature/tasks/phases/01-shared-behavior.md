# Фаза 01 — Планування спільної поведінки

Створюйте невеликі файли `TS-*` лише для чистих правил, валідації, мапінгу або
спільних моделей, потрібних кільком споживачам. Надавайте перевагу модульним
тестам. Не включайте до цих задач питання платформи, мережі та UI.

**Контрольна точка:** кожна потрібна спільна поведінка має одного власника,
точні шляхи та ціль для свідчень фокусного модульного тесту.
