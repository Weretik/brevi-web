# Граф задач функціональності

`TS-*` — одна відповідальність за реалізацію або перевірку. `EN-*` — одна
спільна передумова. ID стабільні, а залежності визначають порядок виконання.

## Фази планування

- [00 — Поведінка та готовність](phases/00-readiness.md)
- [01 — Спільна поведінка](phases/01-shared-behavior.md)
- [02 — Стан і отримання даних](phases/02-state-data.md)
- [03 — Інтерфейс React Web](phases/03-react-web-ui.md)
- [04 — Навігація та браузерні адаптери](phases/04-navigation-browser.md)
- [05 — Інтеграція з API](phases/05-api-integration.md)
- [06 — Перевірка та постачання](phases/06-verification.md)

Фази є індексами планування. Створюйте лише потрібні задачі за
[шаблоном TS](TS-NNN-task.template.md) або [шаблоном EN](EN-NNN-enabler.template.md).
Кожна виконувана задача повинна завершувати розділ `Робота` перевіркою змінених
файлів реалізації на цілісність відповідальності. Розділяйте файл за наявними
архітектурними межами, якщо він поєднує незалежні відповідальності або став
надто складним для зрозумілої підтримки й тестування. Не розділяйте невеликий
цілісний файл лише через кількість рядків.

| ID     | Відповідальність        | Залежить від | Файл                              |
| ------ | ----------------------- | ------------ | --------------------------------- |
| TS-001 | <одна відповідальність> | EN-001       | `<відносне посилання на задачу>`  |
| EN-001 | <одна передумова>       | немає        | `<відносне посилання на enabler>` |
