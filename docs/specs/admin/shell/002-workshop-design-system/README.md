# 002 — Дизайн-система «Цех», нова шапка та бічне меню

- **Поверхня:** React Web, `apps/admin-react`, `libs/admin/core/shell`
- **Статус:** implemented, 2026-11-01
- **Власник:** Admin
- **API:** немає

Власник продукту 2026-10-31 вибрав концепт 2 «Цех» з
[полотна концептів](https://claude.ai/artifact/TngCUEwEgSToLaXK3oaaSJ) і
попросив: (1) зафіксувати його як стандарт дизайну всієї адмінки, щоб нові
фічі робилися за ним, не чіпаючи старі без запиту; (2) переробити шапку та
меню з нуля, як у концепті. Стабільні правила записані в
[стандарті дизайн-системи](../../../../standards/admin/design-system.md); ця
специфікація лише фіксує рішення та обсяг.

## Рішення

- Стандарт «Цех» обов'язковий для нових фіч Admin; посилання в
  `AGENTS.md`, індексі стандартів і `admin-ui.md`.
- Тема розбита за ролями: `palette.ts`, `typography.ts`, `motion.ts`,
  `components.ts`, `brevi-theme.ts`. Шрифти IBM Plex Sans і Mono, `noindex`
  в `index.html`.
- Кольори бічного меню — окремий ключ теми `palette.navigation`; тип і
  augmentation належать shell, значення — застосунку. Без теми застосунку
  shell бере запасні значення.
- Тема за замовчуванням тепер **світла** (замість системної з 001), як
  попросив власник; системна лишається в меню теми.
- Бічне меню: 272/80 px, згортання на десктопі із запам'ятовуванням,
  flyout груп у згорнутому стані, «Головна» на `/`, секції «Робота» і
  «Дані», іконки груп задає застосунок у `legacy-menu.ts`.
- Шапка: хлібні крихти з навігації, поле пошуку, сповіщення, меню теми та
  аватар профілю. На прохання власника (2026-11-01) пошук, сповіщення та
  профіль показані вже зараз, але чесно пояснюють, що функція скоро
  з'явиться; «Вийти» в меню профілю працює.
- Старі сторінки окремо не змінювалися; вони отримують лише загальні
  overrides теми (шрифт, кольори, радіуси, заголовки таблиць).
