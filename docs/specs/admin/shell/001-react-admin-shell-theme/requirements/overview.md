# Оболонка та тема React Admin — правила та приймальні сценарії

## Мета та межі

- **Актор:** співробітник, який відкриває адміністративний застосунок.
- **Мета:** кожна доступна сторінка React Admin має впізнаваний каркас Brevi,
  придатний для навігації на широкому й вузькому екрані.
- **У межах:** спільна область сторінки, логотип, верхня панель, навігація лише
  до наявних маршрутів, корпоративна світла/темна/системна тема, стан
  недоступного маршруту, доступність і адаптивність.
- **Поза межами:** Storefront, перенесення Angular-сторінок, бізнес-вміст,
  dashboard, auth/profile/notifications, пошук, API та backend-контракти.

## Бізнес-правила

- **R-001:** Доступні сторінки Admin мають спільну оболонку з логотипом Brevi,
  верхньою панеллю, навігацією та єдиною областю вмісту.
- **R-002:** Навігація веде тільки до реалізованих маршрутів, позначає
  поточний розділ і працює після прямого відкриття адреси.
- **R-003:** На вузькому екрані меню можна відкрити й закрити з клавіатури;
  після переходу воно закривається, а фокус не залишається в прихованій панелі.
- **R-004:** Світлий, темний і системний режими використовують кольори Brevi;
  вибір користувача зберігається після оновлення сторінки.
- **R-005:** Інтерфейс не показує вигаданих даних користувача, сповіщень,
  недіючого пошуку або посилань на відсутні бізнес-сторінки.
- **R-006:** Невідома адреса показує зрозумілий стан із дією повернення до
  доступного розділу в тій самій оболонці.

## Приймальні сценарії

### SC-001 — Спільний каркас

**Охоплює:** R-001, R-004

- **За умови** користувач відкриває доступну сторінку Admin
- **Коли** сторінка з'являється
- **Тоді** він бачить логотип Brevi, верхню панель, навігацію та вміст у
  спільному оформленні без горизонтального переповнення

### SC-002 — Поточний розділ і пряме посилання

**Охоплює:** R-002

- **За умови** користувач має адресу доступного розділу
- **Коли** він відкриває її без переходу з головної сторінки
- **Тоді** відкривається потрібний вміст, а навігація позначає цей розділ
  поточним

### SC-003 — Навігація на вузькому екрані

**Охоплює:** R-003

- **За умови** користувач працює на вузькому екрані
- **Коли** він відкриває меню, вибирає доступний розділ або закриває меню
- **Тоді** меню закривається після дії, сторінка доступна, а фокус перебуває
  у видимому інтерфейсі

### SC-004 — Вибір теми

**Охоплює:** R-004

- **За умови** користувач обирає світлий, темний або системний режим
- **Коли** він оновлює сторінку або змінює системний режим для системного вибору
- **Тоді** інтерфейс показує відповідну тему Brevi та зберігає вибір

### SC-005 — Лише доступні дії

**Охоплює:** R-005

- **За умови** бізнес-сторінки, профіль і сповіщення ще не підключені
- **Коли** користувач оглядає навігацію та верхню панель
- **Тоді** він не бачить вигаданих персональних даних, сповіщень, недіючого
  пошуку чи активних посилань на відсутні сторінки

### SC-006 — Невідома адреса

**Охоплює:** R-006

- **За умови** користувач відкриває невідому адресу Admin
- **Коли** сторінка завантажується
- **Тоді** він бачить зрозуміле повідомлення й може повернутися до доступного
  розділу без втрати спільного оформлення
