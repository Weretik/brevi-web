# Admin «Швейний цех», stage 4: «Склад тканин»

**Status:** implemented 2026-11-04. Backend: BreviERP PRD-004 (`docs/sdd/specs/production/004-fabric-stock`). Follows [stage 3](../003-order-tracking/README.md).

## Scenarios

| ID     | Scenario                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PRD-S1 | «Склад тканин» (`/production/fabric-stock`, Admin, Manager and the head of the workshop) lists every fabric and colour with «Залишок», «Бронь», «Доступно» and, for Admin and the head of the workshop, the price and value. Search by code, fabric or colour; chips «Під замовлення» and, only when there are some, «Не вистачає» and «Мінус». A planned colour the stock never held is a row too, so the shortage shows. |
| PRD-S2 | A row opens the line card in a side panel: balance, reservation by «Нове» order with links, and every movement with before / change / after, details and author. The head of the workshop and Admin get «Прихід», «Коригування» and «Сторно» (with a reason) of an opening, receipt or correction.                                                                                                                         |
| PRD-S3 | «Прихід» in the header picks a fabric with a FAB- code and a supplier from the server's `choices`, takes metres, date, document and comment; «Початковий залишок» is offered only there. A new colour becomes a new line.                                                                                                                                                                                                  |
| PRD-S4 | «Коригування» takes what was counted and a required reason and shows the change before saving.                                                                                                                                                                                                                                                                                                                             |
| PRD-S5 | Every item of an order card has «Тканина»: plan by colour (план, покрито, видано, бронь, доступно), a warning when the model has no workshop norm, and the issues. «Видати тканину» opens a package with the remaining plan already filled; lines are «Планова», «Заміна» or «Додаткова». «Сторно видачі» asks for a reason.                                                                                               |
| PRD-S6 | «Зведення витрати» shows received, issued, corrected (and the issued value for those who see it) for a period, this month by default. «Excel» downloads the shown rows as CSV.                                                                                                                                                                                                                                             |
| PRD-S7 | «Імпорт» (Admin) of `fabric-stock.json` shows the server preview first: lines, issue errors, the count of movements and issues, and how many reservations differ from the old app.                                                                                                                                                                                                                                         |

## Decisions

- Who may move stock, issue and see the value comes from the server's `permissions` and `canIssue`; the page never decides it.
- Reservation and available metres are the server's; the page only filters and counts them.
- A receipt from the header sends the version of the existing line of that fabric and colour, or none for a new one, so a stale list is a 409 message, not an overwrite.
- No «all OK» marks: only «Мінус», «Не вистачає», a missing norm and a colour the stock never held are marked, each with its reason.
