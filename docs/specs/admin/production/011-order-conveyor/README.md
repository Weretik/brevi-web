# Admin «Швейний цех»: «Конвеєр етапів» on «Виробничі завдання»

**Status:** implemented 2026-11-11. Backend: BreviERP PRD-011 (`docs/sdd/specs/production/011-order-conveyor`). The owner chose concept B «Конвеєр етапів» from the UX analysis and three concepts ([artifact](https://claude.ai/artifact/HjBZbkxzHzXhFfjdSRdbar), 2026-11-11). Changes [filters and «Зведення за моделями»](../010-order-filters-model-summary/README.md): every function stays, only its place changes.

## Decisions

- Only problems are marked (owner rule): no mark for an order on time.
- The same grid serves the client card tab and «Архів цеху» → «Закриті завдання»; there the columns do not sort.
- An API without PRD-011 fields maps to empty lines, an empty conveyor and no strip, so the page works before the backend is deployed.
- Access stays the page `production-orders`; nothing new in «Права доступу».
