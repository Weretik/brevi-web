# Admin «Швейний цех», stage 7: «Звіти цеху» and the overview

**Status:** implemented 2026-11-05. Backend: BreviERP PRD-007 (`docs/sdd/specs/production/007-workshop-reports`). Follows [stage 6](../006-timesheet-payroll/README.md).

## Scenarios

| ID      | Scenario                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PRD-S19 | «Звіти цеху» (`/production/reports`, Admin; the director holds Admin; menu «Швейний цех») picks whole months «Від» – «До» (at most 12, not in the future); «Порівняти з» adds a second period, by default the same number of months right before. ## Decisions

- The numbers are the server's; the page only formats them. Money is never shown as 0 for an unknown price.
- No «all OK» marks: a closed month is not badged; only gaps, warnings, late orders and negative balances are marked.
- The dashboard data comes from `@admin/production/data-access` and `@admin/quotes/data-access`; the app passes `useViewer` from the session roles.
