# 001 — Нагадування в Telegram

- **Поверхня:** React Web, `apps/admin-react`, `libs/admin/reminders/{model,data-access,ui,feature}`
- **Статус:** implemented, 2026-11-01; локальні тести пройдено, не розгорнуто
- **Власник:** Admin
- **API:** BreviERP модуль Reminders, [контракт споживача](contracts/api-contract.md)
- **Бекенд SDD:** BreviERP `docs/sdd/specs/reminders/001-telegram-reminders/`

Власник 2026-10-31 попросив новий пункт меню «Нагадування»: задачі з
термінами для ПП «Бреві», ФОП Согоконь та особисті, бот у Telegram
нагадує за N днів (5 за замовчуванням) лише в робочі дні о 09:00 за Києвом,
з кнопками «Виконано» і «Нагадати пізніше». Make з ботом @brevibuhtime_bot
більше не потрібен. Відповіді на 9 питань зафіксовано в бекенд SDD.

## Рішення

- Група меню «Нагадування» в секції «Робота» з чотирма сторінками:
  «Задачі», «Періоди», «Чати Telegram», «Неробочі дні». Окремі сторінки,
  а не вкладки, щоб хлібні крихти й меню показували, де користувач.
- Новий дизайн «Цех»: щільні таблиці MUI X Data Grid у картці, чіпи
  фільтрів, статус-пігулки з текстом, дати й числа моноширинним шрифтом
  через `var(--admin-font-mono)`.
- Тема публікує `--admin-font-mono` на `:root`, бо бібліотеки не можуть
  імпортувати `typography.ts` застосунку; записано в стандарті дизайну.
- Форма задачі показує поля лише для вибраного правила терміну і живий
  перелік трьох найближчих термінів (`previewReminderDueDates`, із
  затримкою 400 мс, без запиту, поки графік некоректний).
- Конфлікти 409 показують коротку українську причину з бекенду
  («Період уже закрито.»), інші помилки — повідомлення домену.
- Зміна неробочих днів оновлює задачі й періоди: «останній робочий день»
  може зсунутися.
- Особисті задачі видно всім в адмінці (рішення власника 9: адмінкою
  користується одна людина).
