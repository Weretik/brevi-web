# Медіа/Фото — модель даних

| Модель              | Власник                      | Поля та інваріанти                                                                                                                                                                                                                                                        | Споживачі                          |
| ------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| `CatalogMedia`      | `admin-products-data-access` | `id` — додатний integer; `originalFileName` і `contentType` — непорожні строки; `publicUrl` — URL/дозволений origin після runtime-перевірки; `status` — погоджене контрактом значення. `storageKey` лишається transport metadata й не передається UI без окремої потреби. | media hook, gallery, upload result |
| `MediaGalleryState` | `admin-products-feature`     | останній успішний список, `loading`, видима помилка, пошуковий рядок і незалежний стан поточної mutation; список не обнуляється на повторному read failure                                                                                                                | media page і компоненти            |

Generated DTO з `@admin/shared/contracts` використовуються тільки на межі
data-access. Нормалізація пошуку виконується чистою функцією через `trim` і
locale-aware lowercase; вона не змінює серверні дані. Upload response не стає
окремою довготривалою UI-моделлю: після успіху список перечитується.
