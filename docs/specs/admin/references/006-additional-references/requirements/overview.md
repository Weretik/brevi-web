# Додаткові довідники — правила та приймальні сценарії

## Мета та межі

- **Актор:** співробітник Admin.
- **Мета:** працювати з таблицею «Додаткові довідники» у React без втрати наявних дій старого Admin.
- **У межах:** перегляд списку й редагування рядка через діалог, стани даних, помилки, доступність і старий URL.
- **Поза межами:** створення, видалення й масові дії, яких немає в чинній Angular-сторінці; інші пункти меню, нові бізнес-дії з референсних скриншотів, зміна Angular-сторінки й backend без окремої задачі контракту.

## Бізнес-правила

- **R-001:** На сторінці `/references/additional-reference` таблиця «Додаткові довідники» показує перевірені дані, окремі loading/empty/error стани та доступний повтор запиту.
- **R-002:** Таблиця й форма зберігають старі спостережувані дії: перегляд списку й редагування рядка через діалог. Створення, видалення й масові дії не показуються.
- **R-003:** Збереження проходить перевірку полів; помилка не закриває форму й не стирає введені дані.
- **R-004:** Після успішної зміни список оновлюється; невдала зміна залишає попередні дані й показує зрозумілу помилку.
- **R-005:** Це самостійна сторінка; прямий URL відкриває її зі спільною шапкою Brevi.

## Приймальні сценарії

### SC-001 — Список

**Охоплює:** R-001

- **За умови** співробітник відкриває сторінку «Додаткові довідники»
- **Коли** дані завантажені
- **Тоді** він бачить рядки таблиці з потрібними колонками, або зрозумілий порожній стан

### SC-002 — Відкриття редагування

**Охоплює:** R-002, R-005

- **За умови** у списку є записи
- **Коли** співробітник відкриває редагування рядка
- **Тоді** він бачить форму цього запису в межах тієї самої сторінки без переходу на вигаданий URL

### SC-003 — Збереження

**Охоплює:** R-002, R-003, R-004

- **За умови** співробітник редагує запис
- **Коли** він зберігає коректні значення або отримує помилку перевірки
- **Тоді** успіх оновлює список, а помилка лишає форму відкритою з доступним повідомленням

### SC-004 — Недоступні дії

**Охоплює:** R-002

- **За умови** співробітник відкрив таблицю
- **Коли** переглядає дії
- **Тоді** він бачить лише редагування, яке було доступне у старій сторінці, без нових кнопок створення чи видалення

### SC-005 — Помилка, повтор і прямий URL

**Охоплює:** R-001, R-005

- **За умови** співробітник відкрив `/references/additional-reference` напряму або запит завершився помилкою
- **Коли** сторінка завантажується чи він повторює запит
- **Тоді** сторінка доступна, шапка Brevi збережена, а повторний запит показує актуальний результат
