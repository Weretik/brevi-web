# Тканини — правила та приймальні сценарії

## Мета та межі

- **Актор:** співробітник Admin.
- **Мета:** працювати з таблицею «Тканини» у React без втрати наявних дій старого Admin.
- **У межах:** створення, перегляд, редагування, одиночне й масове видалення з підтвердженням; стани даних, помилки, доступність, вкладка й старий URL.
- **Поза межами:** інші пункти меню, нові бізнес-дії з референсних скриншотів, зміна Angular-сторінки й backend без окремої задачі контракту.

## Бізнес-правила

- **R-001:** На сторінці `/references/garment-accessory` таблиця «Тканини» показує перевірені дані, окремі loading/empty/error стани та доступний повтор запиту.
- **R-002:** Таблиця й форма зберігають старі спостережувані дії: створення, перегляд, редагування, одиночне й масове видалення з підтвердженням.
- **R-003:** Збереження проходить перевірку полів; помилка не закриває форму й не стирає введені дані.
- **R-004:** Після успішної зміни список оновлюється; невдала зміна залишає попередні дані й показує зрозумілу помилку.
- **R-005:** Таблиця відображається у вкладці «Тканини» на тій самій сторінці, що й «Фурнітура виробу»; прямий URL відкриває її зі шапкою Brevi.
- **R-006:** Видалення потребує підтвердження; масова дія працює лише з явно вибраними рядками й повідомляє про часткові невдачі без втрати вибору.

## Приймальні сценарії

### SC-001 — Список

**Охоплює:** R-001

- **За умови** співробітник відкриває сторінку «Тканини»
- **Коли** дані завантажені
- **Тоді** він бачить рядки таблиці з потрібними колонками, або зрозумілий порожній стан

### SC-002 — Перегляд і вибір

**Охоплює:** R-002, R-005

- **За умови** у списку є записи
- **Коли** співробітник відкриває доступну дію рядка або вибирає кілька записів
- **Тоді** він бачить відповідний вміст чи стан вибору в межах тієї самої сторінки без переходу на вигаданий URL

### SC-003 — Збереження

**Охоплює:** R-002, R-003, R-004

- **За умови** співробітник створює або редагує запис
- **Коли** він зберігає коректні значення або отримує помилку перевірки
- **Тоді** успіх оновлює список, а помилка лишає форму відкритою з доступним повідомленням

### SC-004 — Видалення

**Охоплює:** R-002, R-004, R-006

- **За умови** співробітник вибрав один або кілька рядків
- **Коли** він підтверджує видалення
- **Тоді** видаляються лише вибрані записи, список оновлюється, а помилки окремих запитів повідомляються

### SC-005 — Помилка, повтор і прямий URL

**Охоплює:** R-001, R-005

- **За умови** співробітник відкрив `/references/garment-accessory` напряму або запит завершився помилкою
- **Коли** сторінка завантажується чи він повторює запит
- **Тоді** правильна вкладка доступна, шапка Brevi збережена, а повторний запит показує актуальний результат
