# 008 — Тканина та фурнітура

- **Поверхня:** React Web
- **Статус:** delivered
- **Власник:** admin/references
- **Оновлено:** 2026-10-01

Одна SDD для спільної сторінки «Тканина та фурнітура» з вкладками «Фурнітура
виробу» й «Тканини». Вона замінює рядкову колонку дій та create/view/edit
діалоги на MUI-контекстне меню й адаптивні праві Drawer, не змінюючи склад доменних
полів попередніх [002](../002-garment-accessories/README.md) і
[003](../003-fabrics/README.md).
