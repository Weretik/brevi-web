# Ревізія «Цех»: сторінка постачальників

Дата: 2026-11-02. Обсяг погоджено власником у чаті: перенести поточну сторінку під показаний макет.

## Мета та межі

Співробітник знаходить постачальника та працює з його контактами на `/references/supplier`.
Зберігаються поточні API, форма-діалог, підтвердження видалення, маршрут і спільна оболонка.
Макет визначає компонування; у продукті показуються дані API без демонстраційних записів і позначки «Демо-дані».
Інші довідники, нові поля, імпорт, експорт та окремі сторінки постачальника поза межами ревізії.

## Правила

- **R-007:** Заголовок, панель інструментів і таблиця відповідають чинній дизайн-системі «Цех», українській локалі та світлій/темній темі; вузький екран прокручує таблицю всередині панелі.
- **R-008:** Локальний пошук без урахування регістру й крайніх пробілів охоплює назву, контактну особу та телефон. Показуються кількість результатів і окремий порожній результат пошуку. Очищення відновлює список; вибір прихованих записів зберігається.
- **R-009:** «Оновити» повторює запит, зберігаючи пошук і вибір; під час запиту повторне оновлення недоступне. Помилка має наявну дію повтору.
- **R-010:** Кнопка з трьома крапками відкриває перегляд, редагування та видалення без зміни вибору рядка. Контекстне меню, Shift+F10 і повернення фокуса зберігаються. Видалення потребує підтвердження.
- **R-011:** Посилання в таблиці відкриває лише HTTP(S), включно з доменом без схеми. Непідтримувані адреси не стають активними; порожні контакти позначаються тире. Форми зберігають поточні перевірки.

## Приймальні сценарії

- **SC-006 / R-007, R-008:** За умови завантаженого списку, коли співробітник вводить назву, контакт або телефон, тоді бачить відповідні записи й кількість; невідповідний запит дає «Постачальників не знайдено», очищення відновлює записи.
- **SC-007 / R-006, R-008:** За умови вибраного запису, коли пошук приховує його, тоді кількість вибраних не змінюється й масове видалення потребує підтвердження саме цього запису.
- **SC-008 / R-009:** За умови відкритої сторінки, коли співробітник оновлює список, тоді бачить актуальні дані без скидання пошуку; під час запиту кнопка недоступна.
- **SC-009 / R-002, R-006, R-010:** За умови фокуса на кнопці дій, коли меню відкривають клавіатурою або мишею, тоді доступні три дії без зміни вибору; Escape повертає фокус на кнопку, а видалення відкриває підтвердження.
- **SC-010 / R-011:** За умови заповненого посилання, коли співробітник переглядає таблицю, тоді коректна HTTP(S)-адреса доступна як посилання, а небезпечна схема — лише як текст.

## Рішення та перевірка

- `feature/pages/suppliers/suppliers-page.tsx` керує запитом і вибором; `ui/components/suppliers/` містить панель інструментів, таблицю та меню. Публічні експорти — через `src/index.ts`.
- Пошук застосовується до завантажених даних; нового API немає. Реальний лічильник і стан вибору замінюють числа макета.
- Семантичні назви кнопок, фокус і сценарії перевіряє наявний компонентний harness; без нового E2E чи зміни пакетів.
- Виконання та свідчення: [TS-006](../tasks/TS-006-workshop-page.md). Історичний закритий SDD `010` не відкривається повторно.
