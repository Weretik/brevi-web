Backend Crm має чотири структурні проєкти, але ще не має клієнтських бізнес-API/сутностей/DbContext; локальна metadata-перевірка не виявила відповідних таблиць.

## Google як основа

[Brevi — новые справочники и расчёты](https://docs.google.com/spreadsheets/d/1BMl9jZLprY-15TfErBi9pbv9e4TVq8DUdjlZ4HvCxRE/edit), locale uk_UA, Europe/Kiev. 2026-10-26 прочитано повні налаштовані діапазони `A1:T1000` вкладок «КП» (13 заголовків), «Позиции КП» (13), «Варианты позиции» (13), «Расчётный состав варианта» (12), «Настройки КП» (11). У відповідях — лише рядок заголовків, жодного запису. Окремої вкладки клієнтів у metadata немає; постачальники не є клієнтами.

| Група полів                                    | Де відображати / хто є власником                                                 |
| ---------------------------------------------- | -------------------------------------------------------------------------------- |
| Клієнт/контакт/телефон/email                   | Вибір CRM та зафіксований одержувач версії, backend Crm                          |
| Менеджер/статус/дати/нотатка                   | Авторизований актор, бізнес-стан та історія; приватна нотатка не входить у PDF   |
| Позиція/тип/товар/назва/опис/фото/порядок      | Редактор позицій, Catalog reference + quote-only презентація                     |
| Варіант/три ціни/показ/метод/причина СІЗ       | Серверні суми, незалежні прапорці видимості, reasoned override лише СІЗ          |
| Склад/норма/час/вартість/зміна                 | Внутрішня калькуляція з версіями входів; не публічний PDF                        |
| Назва підприємства/ЄДРПОУ/ІПН/IBAN/адреса/лого | **Продавець**, версійні налаштування КП, не банківські дані клієнта              |
| PDF/дата надсилання                            | Приватний артефакт і підтверджена подія, не довільне посилання/кнопка скачування |

Повна карта всіх 62 заголовків з перетвореннями — backend SDD `sources/google-field-map.md`. У frontend не дублювати схему зберігання або арифметику. Додаткові поля Brevi — PublicId/revision/requestId, валюта/податкова основа, ідентифікатори версій, audit, ACL/хеші, outbox і звірка — мають явне цільове походження.

## Історичний матеріал

Санітизований експорт Calculator v211 має клієнтські/КП/custom сценарії. Часткова БД містить 958 контрагентів змішаних ролей і 153 заголовки КП; позиції/версії/події/custom versions/issuer settings неповні. 30 записів custom files — metadata, а не наявні байти. Не показувати 958 як кількість підтверджених клієнтів або архів як повністю перенесений. Повна історія потребує backend EN-006 та звіту з усіма статусами рядків/файлів.

Додатково `introduction_saved_templates` і `lib/introduction-proposal.ts` підтверджують власні Manager templates та seasonal first-contact layouts (4/8 моделей); див. [сценарії](requirements/introductions.md). Це окремий presentation kind спільного КП, не лише текст вступу.

Застарілі source email-правила, паролі, OAuth, JS fallback-коефіцієнти та номерні винятки не переносяться. Застосовуються Identity/архітектура й погоджені формули Brevi; source задає поведінку, а не дозвіл дублювати його технічний устрій.
