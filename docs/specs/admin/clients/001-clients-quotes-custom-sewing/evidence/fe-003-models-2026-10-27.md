## Implemented independent scope

- `model/src/models/quotes/`: editable quote/item/variant application models and typed Sewing/PPE/one-off selection. There are no generated transport imports, HTTP calls or duplicate pricing formulas.
- `model/src/entities/quotes/quote-price-basis.ts`: nullable server prices, blocker codes and explicit currency/tax basis. The local form distinguishes saved historical basis from a fresh preview.
- `model/src/mappers/quotes/`: a changed price selection discards its previous basis; semantically equal selection preserves it. Immutable reordering retains logical IDs and monetary snapshots.
- `model/src/validators/quotes/`: positive manual prices and reason, item/text limits, basis/selection coherence and fresh-preview expiry. Historical saved snapshots do not expire for text-only editing. Drafts can retain source blockers and null prices; these are not ready/PDF validation rules.

Public exports use the existing `@admin/clients/model` boundary. Existing routing and data-access code are not presented as implemented quote integration.
