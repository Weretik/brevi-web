## Write and access behavior

Dirty and pending/unknown writes block conflicting commands and destructive navigation. Unknown results retain an exact captured payload and requestId; explicit retry replays both. A 409 preserves input. Normal writes invalidate exact quote and LIST; copy invalidates LIST only. Loss of access (403/404 or canEdit=false) intentionally resets the shared protected admin API cache, including loaded history. Auth stays active; allowed queries re-read. A real shared RTK store with actual editor/list components verifies transfer and purge using intercepted HTTP. The data-access integration fixture uses local node:http, without shared/live backend data.
