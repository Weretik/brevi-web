# Індивідуальне пошиття, шаблони й файли

Спільні правила R-S01–07, сценарії SC-S01–06.

- Редактор приватної конфігурації: назва/тип/сезон, опис/клієнтський коментар/приватна нотатка; тканини/фурнітура/операції з нормами, альтернативи тканин; вишивка/нанесення (місце/макет/внутрішня собівартість/погоджена продажна сума), доставка/пакування.
- Для розрахунку потрібні тканина та операція; джерела/ціни/правила перевіряє backend. Зберегти заблоковану чернетку можна, видати її як готову пропозицію — ні. Не дублювати формулу, коефіцієнти чи округлення у React.
- Кожна альтернатива має власний серверний результат/immutable version. Вибір у КП закріплює версію; наступне редагування custom draft не змінює старий варіант КП.
- Custom-шаблон містить текст вступу/вибір/норми, а не актуальну ціну. Застосування шаблону чи підказки явне, показує зміни й створює нову конфігурацію. Підказка має тип/сезон, кількість моделей і ознаку змінності норми; не підставляє склад автоматично.
- Приватні файли мають стани uploading/validating/ready/failed/missing, фактичний розмір/тип і незалежні «Показувати клієнту» / «Для виробництва». Пропонована початкова межа: PDF/JPEG/PNG, 20 MiB, до 30 файлів; EN-003 остаточно закріплює її у контракті. Браузерна перевірка доповнює серверну, не доводить наявність/безпечність байтів.
- Виробничий пакет створюється лише з вибраної закріпленої версії й дозволених production-файлів. UI не повідомляє «створено замовлення в Цеху», якщо лише згенеровано пакет.

| Сценарій | Given / When / Then                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| SC-S01   | Є чинні тканини/операції → рахує два варіанти → бачить незалежні ціни й версії від сервера                                           |
| SC-S02   | Є нанесення/доставка/пакування → рахує → UI показує backend-суми, не додає вартість/ПДВ вдруге                                       |
| SC-S03   | V1 вже у КП → редагує чернетку/прапорці файлів → старе КП незмінне, V2 обирається явно                                               |
| SC-S04   | Є шаблон/підказка й змінені поточні ціни → застосовує → явна нова конфігурація/серверний розрахунок, не stale ціна шаблону           |
| SC-S05   | Чужий/завеликий/непідтримуваний файл → завантажує чи відкриває → ясна помилка без витоку; missing не показується як готове вкладення |
| SC-S06   | Є готова версія → експортує пакет → бачить закріплені version/hash та стан артефакту, без зовнішньої інтеграції                      |

Для довідникових селекторів визначити loading/empty/error/inactive, збереження власного введення та явну заміну втраченої складової. Для файлів — retry/cancel за можливості адаптера, клавіатурні кнопки й фокус; не використовувати URL із локального preview як постійний fileId.
