# Working with this specification

Read README, the scenario-specific requirement, design/frontend, API handoff and the selected atomic task. Follow the project delivery rules and frontend-feature-delivery skill when implementation is authorized. Do not load unrelated product or historical files.

Scenario IDs are shared with the backend Crm specification; task IDs are repository-local. Keep requirements in Ukrainian, API schemas in canonical backend OpenAPI, generated types untouched, and runtime evidence in dated task evidence files created only when checks run. Resolve only the prerequisite gates that block the selected authorized slice. Do not treat writing a full plan as implementation, user acceptance, migration authorization or permission to send mail.
