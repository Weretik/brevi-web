# FE-007 — Приватні файли, шаблони та підказки

**Стан:** planned. **Covers:** SC-S03–05. **Depends on:** FE-006, FE-EN-002 для backend TS-007/008.

## Шляхи та відповідальність

Заплановані області: `libs/admin/clients/feature/src/custom-sewing/{files,templates,suggestions}/; ui/src/custom-sewing/files/; data-access/src/custom-sewing/`. У скорочених шляхах `feature/`, `ui/`, `model/`, `data-access/` базою є `libs/admin/clients/`. Один компонент/hook/mapper/type — одна основна відповідальність і окремий файл; grouping за сценарієм, public exports через index.ts.

## Робота

Додати upload/validation/ready/failed/missing, quote/production flags, явний apply шаблону/підказки з review. Manager керування власними reusable templates, Admin керування всіма; юридичні/document-layout settings лишаються Admin-only. Не зберігати local blob URL як fileId, не скидати historical file flags при draft edit.

## Test level та Evidence

File size/type/foreign/missing states, retry/focus/flags, explicit template apply after costs change, no silent overwrite tests.

Перевірити існування project targets перед запуском. Для нової поведінки записати focused Red → Green → Refactor → Regression (test name/команда/результат); для discovery/документації — source/link/diff evidence. Evidence зараз **не виконано**. Під час реалізації додати датований `evidence/fe-007.md` у SDD із SHA контракту, зміненими файлами, перевірками та обмеженнями.

## Checkpoint

UI відрізняє metadata від доступного файлу й не видає приватні/production-only вкладення клієнту.

Невирішений prerequisite блокує лише залежний slice; не підміняти його mock API як реалізованою можливістю. [План](../implementation-plan.md).
