## Шляхи та відповідальність

Виконані окремі межі: `libs/admin/clients/model/src/models/introductions/{introduction-layout,introduction-slot-view,introduction-review-state}.ts`, `ui/src/components/introductions/{introduction-format-selector,introduction-season-slots,introduction-selection-review}.tsx` і `feature/src/components/introductions/{introduction-selection-panel,use-introduction-selection}.tsx/ts`, з public exports у model/feature index. `model` визначає позиції та поточну approval gate, `ui` показує серверні labels/blockers, `feature` зв'язує їх через injected callbacks без API. `feature` route, `data-access`, fabric picker, owned template actions, transport validation mapping та pinned document preview залишаються запланованими. Не копіювати backend formula/featured identity matching або реалізацію надсилання.

## Робота

Додати 4/8-slot сценарій із наявних «Розрахунки та КП», власними Manager selection templates, явним apply і поточною серверною ціною нової чернетки. Показувати конкретні season/duplicate/fabric metadata/URL/large-tier blockers від backend. Reuse тих самих ready/PDF/delivery capabilities з introduction presentation kind; історична версія не перераховується. Узгодити schema discriminator/операції через реальний pinned SHA до транспорту.
