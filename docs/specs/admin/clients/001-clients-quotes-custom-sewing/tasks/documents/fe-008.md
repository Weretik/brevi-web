# FE-008 — Реквізити продавця, ready та PDF

**Стан:** planned. **Covers:** SC-D01–02, SC-D04, SC-Q07. **Depends on:** FE-005, FE-007, FE-EN-002 для backend TS-009/010; EN-005.

## Шляхи та відповідальність

Заплановані області: `libs/admin/clients/feature/src/documents/{issuer,preview}/; ui/src/documents/; data-access/src/documents/`. У скорочених шляхах `feature/`, `ui/`, `model/`, `data-access/` базою є `libs/admin/clients/`. Один компонент/hook/mapper/type — одна основна відповідальність і окремий файл; grouping за сценарієм, public exports через index.ts.

## Робота

Admin versioned issuer settings/activation, ready checklist, server number/pinned version, render status/download/error/missing. Відсутні verified legal/tax values пояснюють blocker, не заважають draft save. Не формувати PDF у browser з внутрішнього DTO.

## Test level та Evidence

Issuer permissions, ready block/complete, render retry/missing, download без sent/reprice, actual multipage PDF content/privacy і stable hash evidence.

Перевірити існування project targets перед запуском. Для нової поведінки записати focused Red → Green → Refactor → Regression (test name/команда/результат); для discovery/документації — source/link/diff evidence. Evidence зараз **не виконано**. Під час реалізації додати датований `evidence/fe-008.md` у SDD із SHA контракту, зміненими файлами, перевірками та обмеженнями.

## Checkpoint

Лише перевірений публічний документ закріпленої версії; seller settings не змішані з client details.

Невирішений prerequisite блокує лише залежний slice; не підміняти його mock API як реалізованою можливістю. [План](../implementation-plan.md).
