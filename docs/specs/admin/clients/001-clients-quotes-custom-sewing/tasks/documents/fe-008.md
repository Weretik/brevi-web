# FE-008 — Реквізити продавця, ready та PDF

**Стан:** P5 реалізовано та локально технічно прийнято в погоджених межах: реквізити, ready, render/status/download PDF та перевірка фактичного документа. [Підсумкове evidence](../../evidence/p5-local-rendered-acceptance-2026-10-30.md). Production rollout і бізнес-приймання є окремими перевірками. **Covers:** SC-D01–02, SC-D04, SC-Q07. **Depends on:** FE-005, FE-007, FE-EN-002 для backend TS-009/010; EN-005. Раніші checkpoints нижче описують історичні межі перевірки.

## Шляхи та відповідальність

Реалізовані області: `feature/src/pages/documents/` (сторінка реквізитів), `feature/src/components/documents/` (панель КП), `feature/src/hooks/documents/` (дії, polling та browser save), `ui/src/{forms,components}/documents/`, `model/src/models/documents/`, `data-access/src/api/documents/`, `data-access/src/api/quotes/documents/` і `data-access/src/cache/quotes/` (очищення приватного кешу при втраті доступу). У скорочених шляхах базою є `libs/admin/clients/`. Транспортні типи беруться лише зі згенерованого OpenAPI.

## Робота

Admin versioned issuer settings/activation, ready checklist, server number/pinned version, render status/download/error/missing. Відсутні verified legal/tax values пояснюють blocker, не заважають draft save. PDF не формується у browser з внутрішнього DTO. Після перезавантаження ready КП повторний render повертає серверний artifact ID; запит prepare повторюється з тим самим requestId до підтвердження результату.

## Test level та Evidence

Issuer permissions, ready block/complete, render retry/missing, download без sent/reprice, actual multipage PDF content/privacy і stable hash evidence.

Перевірити існування project targets перед запуском. Поточні автоматичні докази та невиконані ручні acceptance checks наведено в [датованому evidence](../../evidence/fe-008-integration-2026-10-29.md).

## Checkpoint

Лише перевірений публічний документ закріпленої версії; seller settings не змішані з client details.

Невирішений prerequisite блокує лише залежний slice; не підміняти його mock API як реалізованою можливістю. [План](../implementation-plan.md).
