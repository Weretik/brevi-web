# Список товарів Admin

- **Статус:** blocked — свідчення застарілої реалізації не відповідають поточному дереву
- **Поверхня:** React Web
- **Оновлено:** 2026-09-08

Специфікація описує пошук, фільтри, server sorting/pagination і стани списку
товарів. Історичні phase records збережені без переписування evidence, але
згадані в них `libs/admin/products/*` зараз відсутні. `apps/admin-react` вже
має shell і test target, але не має списку товарів.
