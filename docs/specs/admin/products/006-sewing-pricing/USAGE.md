# Usage

Open a saved Sewing Product, select an Article in its composition section, and save any composition edits. Review actual materials and operations through the existing editor. A manager can calculate a retained price; blockers explain the data that still needs attention. Inspect component costs and quantity bands, then publish explicitly. If inputs changed, calculate again. Readers see published prices without write actions. Product lists/cards use published Article wholesale prices; missing publication is shown explicitly. No imported composition is reviewed automatically.
