# EN-003 — Налаштування середовища браузерних E2E-тестів

- **ID задачі:** EN-003
- **Уможливлює:** SC-001
- **Залежить від:** немає
- **Точні шляхи:** `nx.json`, `apps/admin-react-e2e/project.json`, `apps/admin-react-e2e/playwright.config.ts`, `apps/admin-react-e2e/src/admin-react.smoke.spec.ts`
- **Рівень тестування:** перевірка налаштування

## Робота

- [x] Додати inferred-проєкт Nx Playwright і початковий smoke-тест Chromium.
- [x] Залишити E2E-тести функціональності лише для окремо обґрунтованих критичних сценаріїв.

## Свідчення

- Чому поведінковий Red не має сенсу: ця передумова створює межу браузерного
  тестування й не реалізує поведінку списку товарів.
- Перевірені наявні інструменти: установлені `@nx/playwright` і
  `@playwright/test`; генератор конфігурації завершився помилкою через дублікати
  inferred-назв проєктів у наявних бібліотеках.
- Альтернативна команда або перевірка та результат: `npx playwright install chromium`
  — пройшла; `npx nx run admin-react-e2e:e2e` — один smoke-тест Chromium
  пройшов; `npx nx run admin-react-e2e:typecheck` і `lint` — пройшли.
- Уможливлена поведінкова задача: майбутня E2E-задача списку товарів, лише якщо
  SC-001 класифіковано як критичний браузерний сценарій.
