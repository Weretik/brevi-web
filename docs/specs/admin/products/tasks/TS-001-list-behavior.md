- **ID задачі:** TS-001
- **Охоплює:** SC-001, SC-002, SC-003, SC-004, SC-005, SC-006
- **Залежить від:** EN-001, EN-002
- **Точні шляхи:** `libs/admin/products/model/src/lib/products-list-query.ts`, `libs/admin/products/data-access/src/lib/products-api.test.ts`, `libs/admin/products/feature/src/lib/products-page.tsx`, `libs/admin/products/feature/src/lib/products-page.test.tsx`
- **Рівень тестування:** фокусний інтеграційний + компонентний

## Робота

- [ ] Додати фокусні тести ризиків запитів і стану та видимих користувачу взаємодій зі списком без дублювання повних сценаріїв на обох рівнях.
- [ ] Виправити лише дефекти списку товарів, виявлені цими тестами, і завершити приймальну перевірку у браузері.
