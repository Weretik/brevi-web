# Фаза 02 — Стан і дані

- TS-001–TS-005: використовувати поточні read hooks і окремий detail GET для прямого URL.
- TS-011: повний detail із write response передати до картки одноразово; довгоживучий кеш не вводити.
- TS-012: зберігати форму на помилці, розрізняти loading, empty, 404, 409 і мережевий стан.

**Контрольна точка:** жоден stale response не перезаписує новий ID/query; read-only дані не потрапляють у write.
