# Фаза 01 — Спільні правила

- TS-001: default/supported sort і нерозрахована ціна.
- TS-003: політика безпечного Markdown і показ двох мов після EN-001.
- TS-006–TS-009: Ready media, `sortOrder`, обмеження Sewing/Ppe.
- TS-010: збереження спільних полів при підтвердженій зміні типу.

**Контрольна точка:** правила мають вузькі модельні/компонентні тести, без дублювання в JSX і transport.
