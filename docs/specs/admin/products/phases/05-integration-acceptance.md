# Фаза 5: інтеграційна ручна прийомка

**Статус:** draft  
**Залежить від:** [фаза 4](04-mui-data-grid.md)  
**Завершує:** SDD списку товарів Admin

## Мета

Підтвердити, що endpoint, RTK Query, toolbar і Data Grid працюють разом за
погодженим контрактом без нецільових змін.

## Межі

- У межах: lint, build, ручна перевірка запитів і UX, виправлення дефектів у
  межах цієї feature.
- Поза межами: автоматизовані тести, нові можливості, зміна API-контракту без
  нової SDD.

## Сценарії приймання

1. Початкове відкриття надсилає `InStock=false`, `Sort=0`, `Page=1`,
   `PageSize=20` і показує server result.
2. Search надсилається лише через Enter/кнопку; очистка й reset повертають
   очікувані результати.
3. Boolean-фільтри та ціна формують коректні query params; невалідна ціна не
   породжує запит.
4. Pagination і sort формують правильні `Page`, `PageSize`, `Sort`; `rowCount`
   відповідає `totalRecords` API.
5. Loading, empty, API error і retry зрозумілі та доступні з клавіатури.

## Критерії приймання

- [ ] Виконано `npx nx lint admin-products-feature`.
- [ ] Виконано `npx nx lint admin-products-data-access`.
- [ ] Виконано `npx nx lint admin-products-ui`.
- [ ] Виконано `npx nx build admin`.
- [ ] Ручно перевірено стани та viewport 320/768/1200 px у світлій і темній темі.
- [ ] Не змінено storefront, глобальний Redux store, маршрути чи непов’язані
      бібліотеки.

## Відкриті питання

- Автоматизовані тести додаються окремою задачею після цієї поставки.
