# Список товарів Admin — правила та приймальні сценарії

## Бізнес-правила

- **R-001:** Початковий список показує всі товари з сортуванням за ID,
  починаючи з першої сторінки розміром 20.
- **R-002:** Пошук застосовується лише після підтвердження й ігнорує пробіли на
  початку та в кінці.
- **R-003:** Зміна пошуку або фільтра повертає список на першу сторінку.
- **R-004:** Ціновий діапазон приймає невід'ємні числа; нижня межа не може бути
  більшою за верхню.
- **R-005:** Сортування та пагінація виконуються сервером, а загальна кількість
  товарів походить із відповіді сервера.
- **R-006:** Loading, empty та error є різними доступними станами; retry
  повторює поточний запит без втрати умов.

## Приймальні сценарії

### SC-001 — Початковий список

**Охоплює:** R-001, R-005

- **За умови** менеджер відкриває каталог товарів
- **Коли** список завантажується вперше
- **Тоді** менеджер бачить першу сторінку всіх товарів, відсортованих за ID

### SC-002 — Підтверджений пошук

**Охоплює:** R-002, R-003

- **За умови** менеджер ввів текст у поле пошуку
- **Коли** менеджер підтверджує пошук
- **Тоді** список показує першу сторінку товарів за введеним текстом

### SC-003 — Застосування фільтрів

**Охоплює:** R-003, R-004

- **За умови** менеджер задав ознаки або коректний діапазон ціни
- **Коли** менеджер застосовує умови
- **Тоді** список показує першу сторінку товарів, які відповідають умовам

### SC-004 — Некоректний діапазон ціни

**Охоплює:** R-004

- **За умови** нижня межа ціни більша за верхню
- **Коли** менеджер намагається застосувати діапазон
- **Тоді** менеджер бачить доступне повідомлення про помилку, а список не оновлюється

### SC-005 — Сортування й пагінація

**Охоплює:** R-005

- **За умови** каталог містить кілька сторінок
- **Коли** менеджер змінює сортування, сторінку або розмір сторінки
- **Тоді** менеджер бачить відповідну серверну сторінку в обраному порядку

### SC-006 — Помилка і повторення

**Охоплює:** R-006

- **За умови** поточний запит завершився помилкою
- **Коли** менеджер повторює завантаження
- **Тоді** повторюються ті самі умови й успішна відповідь замінює повідомлення
