# Frontend engineering rules

Цей каталог містить сталі правила для frontend-змін. Feature-специфікації
посилаються на ці документи, а не дублюють їх.

- [Admin code rules](admin-code-organization.md) — межі libraries, state і структура React-коду.
- [Admin UI rules](admin-ui.md) — мова, MUI, accessibility і UI states.
- [Mobile code rules](mobile-code-organization.md) — Expo Router, libraries, state і platform APIs.
- [Mobile UI rules](mobile-ui.md) — React Native Paper, safe area і mobile states.
- [API and data rules](api-data-rules.md) — DTO, RTK Query, mappers, errors і contracts.
- [Testing rules](testing-rules.md) — вибір перевірок та їх фіксація.
- [Delivery rules](delivery-rules.md) — SDD flow, scope і definition of done.
