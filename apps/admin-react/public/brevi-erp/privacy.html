Політика конфіденційності BreviERP

Редакція від 30 жовтня 2026 року

1. Сервіс і контакт

Ця політика стосується BreviERP на домені office.brevi.com.ua, його робочих даних та підключення Google для надсилання комерційних пропозицій. З питань обробки даних, доступу, виправлення або видалення звертайтеся до команди Brevi: pp.brevi@gmail.com. Політика не описує інші застосунки Brevi, зокрема старий калькулятор.

2. Які дані обробляються

  • Робочий обліковий запис працівника та його роль; введені працівниками контактні дані клієнтів і одержувачів, матеріали калькуляцій, комерційні пропозиції, PDF та інші робочі документи.
  • Під час підключення Google — ідентифікатор облікового запису, підтверджена адреса email, надані дозволи, access token і refresh token для виконання дозволених дій без повторного введення пароля.
  • Під час надсилання — адреси відправника й одержувача, тема, текст листа та PDF-вкладення; технічний ідентифікатор повідомлення, пов'язана версія КП, час, стан і події спроби надсилання.
  • Технічні дані, потрібні для роботи, контролю доступу та діагностики: записи про дії, помилки й запити до сервісу. Конкретний склад серверних журналів залежить від робочого середовища.

BreviERP не запитує пароль Google. Публічні інформаційні сторінки не містять рекламних трекерів або сторонніх аналітичних скриптів.

3. Дозволи Google та призначення

Для поштового підключення передбачені openid і email для підтвердження облікового запису та https://www.googleapis.com/auth/gmail.send для надсилання погоджених працівником листів від підключеної скриньки.

Поштова функція не потребує читання вхідної скриньки, списку листів або вкладень із Gmail. Автоматичне читання пошти для звірки результатів не входить до цього режиму. Невизначений результат перевіряє уповноважена людина безпосередньо у Gmail; він не є підтвердженням доставки та не запускає автоматичне повторне надсилання.

Використання інформації, отриманої через Google API, відповідає Google API Services User Data Policy, включно з вимогами Limited Use. Дані Google використовуються лише для заявлених користувацьких функцій підключення та надсилання, їх безпеки і підтримки. Вони не продаються, не використовуються для реклами, профілювання чи навчання моделей штучного інтелекту загального призначення.

4. Обробка на сервері та передавання

Дані листа, вкладення, історія спроб і облікові дані OAuth обробляються сервером BreviERP. Google отримує дані, необхідні для авторизації та надсилання; обраний одержувач отримує лист і вкладення. Робочі дані зберігаються в інфраструктурі, яку використовує Brevi для сервісу; її постачальники можуть обробляти їх у межах розміщення, зберігання та технічного забезпечення сервісу.

Доступ працівників обмежується їхніми повноваженнями. Людський доступ до даних Google допускається лише за належною згодою користувача, для забезпечення безпеки, виконання вимог закону або в інших випадках, дозволених політикою Google Limited Use. Дані не передаються для сторонніх маркетингових цілей. Законні вимоги уповноважених органів розглядаються в межах застосовного права.

5. Зберігання та захист

Робочі документи й історія зберігаються, доки вони потрібні для роботи із замовленнями, підтвердження дій, вирішення спорів або виконання застосовних обов'язків. Токени потрібні на період активного підключення; після його припинення вони підлягають видаленню з активної конфігурації. Універсальний строк для всіх категорій даних не встановлюється цією політикою; щодо конкретних записів і строків звертайтеся за контактною адресою.

Для робочого розміщення необхідні HTTPS, розмежування доступу та захищене зберігання секретів поза вихідним кодом. Токени, секрети клієнта й одноразові коди не повинні потрапляти в загальнодоступні журнали. Жодна система не забезпечує абсолютного захисту; про підозрілий доступ повідомляйте команді Brevi.

6. Відключення, виправлення та видалення

Власник Google-акаунта може відкликати доступ BreviERP у налаштуваннях підключень Google. Після відкликання сервіс втрачає можливість користуватися цим дозволом; адміністратор також має прибрати токени із середовища BreviERP. Відкликання доступу саме по собі не видаляє вже створені КП, історію надсилання або листи у скриньках відправника й одержувача.

Щоб запитати доступ до своїх даних, виправлення або видалення, напишіть на pp.brevi@gmail.com із темою «BreviERP — дані». Вкажіть адресу облікового запису або достатні дані для пошуку запису; не надсилайте паролі чи токени. Перед виконанням запиту може знадобитися перевірка особи та повноважень.

Команда розгляне запит, повідомить про виконані дії або підстави збереження окремих записів. Видалення з резервних копій може відбутися під час їх планової заміни; доступ до таких копій має залишатися обмеженим. Дані, які закон вимагає зберігати, можуть бути збережені в необхідному обсязі. Листи у Gmail та в одержувачів обробляються окремо відповідними власниками скриньок.
